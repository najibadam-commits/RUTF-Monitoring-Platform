# Proposal screenshots

Captured 7 October 2026 from the production build (`npm run demo`, http://localhost:3001), signed in
as Super Admin, with the DUMMY demo data (September 2026, Katsina State). Screens are 1440 × 900 at
2× sharpness (2880 × 1800 px); the Monthly Programme Report is its full-length print view. Figures
are demo data: they illustrate the platform, not real programme results.

| File | Screen | Suggested caption |
| --- | --- | --- |
| `01-landing.png` | Landing page | Every sachet of RUTF tracked, verified and accounted for, from the State store to the OTP site. |
| `02-overview-dashboard.png` | Overview Dashboard | The month at a glance: what needs attention first, stock on hand at every level, and reporting, dispensing and Findings in one view. |
| `03-situation-map.png` | Situation Map | Every store and OTP site on the map, with LGAs shaded by open Findings, low stock or risk. |
| `04-findings-register.png` | Findings Register | Every discrepancy, raised automatically from the ledger and supervision visits, with its owner and status until verified closure. |
| `05-finding-detail.png` | Finding detail | One Finding's evidence and full history: raised by an automatic check, approved, assigned, and followed to closure. |
| `06-corrective-action-tracker.png` | Corrective Action Tracker | Every approved Finding by stage (Assigned, Being addressed, Action recorded, Verified & closed, and reopened cases in red), oldest and late first, against a 30-day target. |
| `07-accountability-scorecard.png` | Accountability Scorecard | A simple, transparent score for each LGA (half closure, half timeliness), with its six-month trend. |
| `08-stock-ledger-store.png` | Stock Ledger, one store | Balances computed from entries, never typed in: lots and expiry, month-by-month reconciliation, and an integrity line (entries never edited or deleted). |
| `09-transfers.png` | Transfers | The chain of custody for every shipment: delivered in full, in transit, and any shortfall raised as a Finding. |
| `10-stock-reconciliation.png` | Stock Reconciliation | Each store's month-end count against the ledger, with months of stock, stockout days and expired stock. |
| `11-last-mile-dispensing.png` | Last-Mile Dispensing | Did the RUTF reach the children? Sachets dispensed against prescribed, children seen, and the supervisor's register check. Aggregate figures only. |
| `12-risk-based-supervision.png` | Risk-Based Supervision | Store checks and OTP verifications, GPS-verified on site, with coverage and visits by supervisor. |
| `13-dhis2-triangulation.png` | DHIS2 Triangulation | The national HMIS beside the ledger, report by report: agreement by indicator and the differences to review. |
| `14-monthly-programme-report.png` | Monthly Programme Report | One page for the State, LGAs and partners, written from live data and ready to print. |
| `15-data-access-requests.png` | Data Access Requests | Data leaves the platform only with approval: scoped to the requester, downloadable once, and on record. |
| `16-users-and-access.png` | Users & Access | Six roles, each seeing and changing only its own area, enforced by the database for the web, the app and the API. |
| `17-offline-sync-health.png` | Offline Sync Health | Phones that record without a signal and report what is still waiting, so no record is lost. |
| `18-settings-security.png` | System Settings | The go-live checklist and the automatic checks that run every night. |
